Check the rollout:

  kubectl rollout status deployment/{{ include "taskboard.backendName" . }} -n {{ .Release.Namespace }}

{{- if .Values.ingress.enabled }}

Open the app through the Ingress:
{{- if .Values.ingress.host }}
  http://{{ .Values.ingress.host }}/          (frontend)
  http://{{ .Values.ingress.host }}/docs      (FastAPI Swagger)
  Map {{ .Values.ingress.host }} to your ingress controller's address (e.g. in /etc/hosts).
{{- else }}
  kubectl get ingress {{ include "taskboard.fullname" . }} -n {{ .Release.Namespace }}
  Then browse to the ADDRESS column (/, /docs, /api/tasks).
{{- end }}
{{- else }}

Open the app with a port-forward:
  kubectl port-forward svc/{{ include "taskboard.frontendName" . }} 3000:{{ .Values.frontend.service.port }} -n {{ .Release.Namespace }}
  kubectl port-forward svc/{{ include "taskboard.backendName" . }} 8000:{{ .Values.backend.service.port }} -n {{ .Release.Namespace }}
  -> http://localhost:3000  and  http://localhost:8000/docs
{{- end }}
